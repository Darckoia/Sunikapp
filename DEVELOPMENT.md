# SUNIKFLOW Development Setup Guide\n\n## Prerequisites\n\n- Python 3.9+\n- Git\n- Docker & Docker Compose (optional)\n- PostgreSQL (optional, for production)\n\n## Installation\n\n### Quick Setup\n\n```bash\n# 1. Clone repository\ngit clone https://github.com/darcko2/Sunikapp.git\ncd Sunikapp\n\n# 2. Install uv\ncurl -LsSf https://astral.sh/uv/install.sh | sh\n\n# 3. Sync dependencies\nuv sync\n\n# 4. Copy environment file\ncp .env.example .env\n\n# 5. Initialize database\npython setup_db.py\n```\n\n## Development Server\n\n### Start development server\n```bash\nuv run python -m uvicorn backend.main:app --reload\n```\n\nAccess:\n- Frontend: http://localhost:8000\n- API Docs: http://localhost:8000/docs\n- ReDoc: http://localhost:8000/redoc\n\n### Start with Docker\n```bash\ndocker-compose up\n```\n\n## Environment Configuration\n\nEdit `.env` file to customize settings:\n\n```env\n# Database\nDATABASE_URL=sqlite:///./sunikapp.db\n\n# API\nAPI_HOST=0.0.0.0\nAPI_PORT=8000\nAPI_RELOAD=true\n\n# Environment\nENVIRONMENT=development\nDEBUG=true\n\n# Audio\nSAMPLE_RATE=44100\nBIT_DEPTH=16\n```\n\n## Code Quality\n\n### Format Code\n```bash\n# Install dev dependencies\nuv pip install black isort flake8 pytest\n\n# Format\nblack backend/\nisort backend/\n\n# Lint\nflake8 backend/\n\n# Test\npytest tests/\n```\n\n## Docker Development\n\n### Start services\n```bash\ndocker-compose up\n```\n\n### Stop services\n```bash\ndocker-compose down\n```\n\n### View logs\n```bash\ndocker-compose logs -f api\n```\n\n## Production Setup\n\n```bash\n# Configure production environment\ncp .env.example .env.production\n# Edit .env.production with production settings\n\n# Start production\ndocker-compose -f docker/compose.prod.yml up -d\n```\n\n## Troubleshooting\n\n### Port 8000 already in use\n```bash\nlsof -i :8000\nkill -9 <PID>\n```\n\n### Database connection error\n```bash\n# Reset SQLite database\nrm sunikapp.db\npython setup_db.py\n```\n\n### Module not found\n```bash\n# Resync dependencies\nuv sync\n```\n\n## Development Workflow\n\n1. Create feature branch: `git checkout -b feature/your-feature`\n2. Make changes and test\n3. Format code: `black backend/ && isort backend/`\n4. Commit: `git commit -m \"Add feature\"`\n5. Push: `git push origin feature/your-feature`\n6. Create Pull Request\n\n## API Documentation\n\n- **Swagger UI**: http://localhost:8000/docs\n- **ReDoc**: http://localhost:8000/redoc\n- **API Guide**: [API.md](API.md)\n\n## Additional Resources\n\n- [Quick Start](QUICKSTART.md)\n- [Architecture](ARCHITECTURE.md)\n- [Contributing](CONTRIBUTING.md)\n- [Deployment](DEPLOYMENT.md)\n\n---\n\nHappy coding! 🎵\n
